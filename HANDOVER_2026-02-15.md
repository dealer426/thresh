## Known Issues / Expected Behavior

### Platform-Specific:
1. **Load Average**: Only available on Linux/macOS, will be `null` on Windows (expected)
2. **Docker Detection**: Windows uses Docker Desktop, may show different runtime info
3. **IP Detection**: Windows may show different network interfaces (Hyper-V, WSL)

### MCP/VSCode:
1. **Parallel Creation**: Copilot must use `names` array - if it calls tool 3 times instead, the description may need tweaking
2. **Schema Validation**: Array parameters must have `Items` property defined (fixed in this session)
3. **Stdio Transport**: VSCode only supports stdio, not HTTP (this is by design)

### Performance:
1. **External IP**: 3-second timeout for ipify.org - may be null if offline/blocked
2. **Parallel Operations**: Speed improvement varies based on system resources
