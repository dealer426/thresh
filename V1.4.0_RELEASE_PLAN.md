## Overview

Version 1.4.0 introduces significant architectural changes, including a **breaking change** to the command structure (flat → grouped commands). This release requires comprehensive documentation updates across all markdown files and Docusaurus versions.

---

## 📊 Scope of Changes

### Code Changes (24 commits ahead of main)

**Major Features:**
1. ✅ **BREAKING: Grouped Blueprint Commands**
   - `thresh blueprints` → `thresh blueprint list`
   - `thresh generate` → `thresh blueprint generate`
   - New: `thresh blueprint delete`

2. ✅ **Parallel Environment Creation** (MCP)
   - Create multiple environments simultaneously
   - New MCP tools for parallel operations

3. ✅ **Enhanced System Metrics**
   - IP address display
   - Load average monitoring
   - Docker storage information
   - JSON export support

4. ✅ **Multi-Platform Improvements**
   - Linux/Docker/nerdctl support
   - macOS containerd support
   - Platform-aware AI blueprint generation
   - Docker Hub image support

5. ✅ **CI/CD Fixes**
   - UPX compression (Linux/Windows only)
   - macOS build fixes (Homebrew UPX)
   - Multi-platform release automation

## 🔍 Breaking Changes Documentation

### Command Migration Guide

Create comprehensive migration guide in docs:

**Old Commands (v1.3.0 and earlier):**
```bash
thresh blueprints                    # List all blueprints
thresh generate "description"        # Generate blueprint
# No delete command existed
```

**New Commands (v1.4.0+):**
```bash
thresh blueprint list                # List all blueprints
thresh blueprint generate "desc"     # Generate blueprint
thresh blueprint delete <name>       # Delete blueprint (NEW)
```

### Backwards Compatibility
- ❌ No aliases provided (clean break)
- ✅ System.CommandLine provides suggestions for typos
- ✅ Old commands show helpful error messages
